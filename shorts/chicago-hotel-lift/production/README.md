# Chicago hotel-lift Short — how to build

The project is a 60 s vertical animated documentary made with Remotion (React + SVG). The narration comes from local Piper TTS, and the sound effects and music are synthesized procedurally in Python.

```
shorts/chicago-hotel-lift/
├── production/        script.md, scene-plan.md, source-notes.md, lines.json (narration + caption chunks)
├── src/               Remotion project
│   ├── Short.tsx      composition: scenes keyed to narration timing, transitions, captions, audio
│   ├── components/    Person (character rig), Hotel, World (camera/parallax, sky, rain, buildings…), Captions
│   ├── scenes/        S1Hook … S9Outro
│   ├── lib/           animation helpers + reusable poses (idle, walking, cranking)
│   └── timing.json    generated by tools/make_voice.py
├── public/audio/      narration.wav, sfx.wav, music.wav, mix.wav (final mix used by the render)
├── tools/             make_voice.py, make_audio.py, build.sh, stills.sh
└── output/short.mp4   final render
```

## Prerequisites
- Node 18+ and ffmpeg
- A Chromium binary. Remotion can download its own, or you can point `CHROME` at an existing one.
- Python 3 with `piper-tts` and `numpy`, plus the voice model:

```bash
python3 -m venv .venv && .venv/bin/pip install piper-tts numpy
mkdir -p tools/voices && cd tools/voices
curl -LO https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ryan/high/en_US-ryan-high.onnx
curl -LO https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ryan/high/en_US-ryan-high.onnx.json
cd ../..
```

## Build
```bash
npm install
PY=.venv/bin/python CHROME=/path/to/chrome tools/build.sh                # voice → SFX/music → loudnorm (-14 LUFS) → render
PY=.venv/bin/python CHROME=/path/to/chrome tools/build.sh --skip-voice   # keep the existing narration
```
The output is `output/short.mp4`: 1080×1920, 30 fps, H.264 + AAC.

Other commands:
- `npm run studio`: interactive preview in the Remotion Studio
- `npm run typecheck`
- `tools/stills.sh 0 150 300`: renders QC stills of the given frames and a contact sheet in `output/qc/`

## Editing
- **Change the words:** edit `production/lines.json`. `captions` holds the on-screen chunks (words in ALL CAPS are highlighted). `tts` is an optional spelling used only for pronunciation. Then rerun `tools/build.sh`. Scene lengths, caption timing and SFX placement all follow the new narration automatically.
- **Caption timing** is estimated from character counts within each narration line, not from word-level forced alignment.
- **Characters:** `CAST` in `src/components/Person.tsx`. Poses are numeric, so they interpolate cleanly.

## V2: 3D engine (look-dev)
The skill was upgraded to `viral-animated-shorts-studio` (V2), which asks for dimensional animation. The 3D engine is in `src/three/`:

- `kit.tsx`: helpers (IK, easing, camera, procedural textures, sky, glow)
- `Character3D.tsx`: the 3D character rig and cast
- `sets.tsx`: hotel, jackscrews, cribbing, street set, props
- `ExteriorShot.tsx`, `RoomShot.tsx`: the three preview shots
- `PreviewV2.tsx`: the preview composition (the hook, 5.7 s)

```bash
CHROME=/path/to/chrome npm run preview3d      # renders output/preview_v2.mp4
tools/stills3d.sh PreviewV2 12 75 128         # QC stills in output/qc3d/
```
3D compositions must be rendered with `--gl=angle --concurrency=1` (see `production/style-bible-v2.md`).
