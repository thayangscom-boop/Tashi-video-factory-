# claude-3d-animated-shorts: test render

`office-skit-demo.mp4` is the skill's bundled 10 s demo ("Trả lời tất cả" / "Reply all"), rendered in this cloud container at 1080×1920, 30 fps, 300 frames. The animation is unmodified upstream. The sound-effect bed comes from `tools/demo_skit_sfx.py`, made with the skill's own generators. There is no voice, because upstream uses ElevenLabs with a Vietnamese voice and no key is configured.

The story: a man in a vest smugly replies to the boss's "Meeting at 9" email, clicks **Reply all** (to 300 people), and every coworker's screen pings. Heads turn, "!" bubbles appear, there is a whip pan between reactions, and a dolly-zoom closes on his "oh no" face.

How it was rendered: see `.claude/skills/claude-3d-animated-shorts/INSTALL-NOTES.md`.
